Sawarga Courtyard

A real-time reconstruction of the open-air courtyard at Summarecon Mall Bandung. The plaza is intentionally left clean so the environment can be reused.

Desktop

  • Click lock the camera and look
  • WASD walk
  • Shift sprint
  • F toggle fly mode
  • Space / Ctrl up / down while flying
  • O orbit mode · R reset
  • L layout overlay
  • 1 2 3 camera presets

Mobile

  • Left side: drag to move
  • Right side: drag to look
  • Fly toggles vertical movement
  • Use ↑ / ↓ while flying
  • Preset pills jump to viewpoints
  • Layers icon toggles the event layout

Environment textures and HDRIs from Poly Haven (CC0). Built with Three.js. Summarecon name and marks belong to their respective owners.
